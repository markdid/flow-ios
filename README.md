# Flow for iOS

A private YouTube client for iPhone, modelled on [Flow](https://github.com/Flow-Tube/Flow) for Android.
No Google account, no ads, no tracking: history, subscriptions, playlists and recommendations stay on the device.

Not an official Flow release. Not affiliated with Google or YouTube.

## Features

- **Home**: recommendation feed built on the device from watch history and subscriptions, Continue watching, topic chips
- **Search**: live suggestions, recent searches, filters
- **Playback**: native AVPlayer up to 1080p (H.264), quality menu, audio-only, background audio, Picture in Picture, lock-screen controls, resume position, autoplay
- **Watch page**: likes, description, comments with replies, related videos, swipe down to the mini player
- **Channels**: banner, avatar, stats, Videos and Live tabs, local subscribe
- **SponsorBlock**: per-category auto-skip, segment bar under the video, undo, manual skip button
- **Library**: history, Watch later, playlists, YouTube playlist import, NewPipe and Google Takeout import

## How it works

Stream URLs are extracted on the device with [YouTubeKit](https://github.com/alexeichhorn/YouTubeKit)
(local mode only; YouTube's player script runs in JavaScriptCore). Separate DASH video and audio
tracks are composed into one AVPlayer item. Search, watch pages, channels and comments use
InnerTube parsers in `FlowCore`. Requests go directly from the phone to YouTube; there is no
intermediate server.

## Known limitations

- Some "made for kids" videos are refused by YouTube's stream servers. The app shows an error
  instead of playing them.
- Extraction breaks when YouTube changes its player; updating YouTubeKit usually fixes it.
- Not distributable through the App Store. Install from Xcode with your own signing team.

## Build

Requires Xcode and [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```sh
xcodegen generate
open FlowPrototype.xcodeproj   # set your team, pick a device, run
```

FlowCore tests: `swift test --package-path FlowCore`
